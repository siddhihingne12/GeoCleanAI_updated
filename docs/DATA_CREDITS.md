# Data, libraries and attribution

- **Mapillary photographs**: https://help.mapillary.com/hc/en-us/articles/115001770409-CC-BY-SA-license-for-open-data. Display contributor, capture date, source-image link and CC BY-SA attribution. Preserve the applicable image licence when sharing analysed crops. A Mapillary account and registered app provide the browser client token.
- **TACO**: Pedro F. Proença and Pedro Simões, *TACO: Trash Annotations in Context for Litter Detection*, 2020. https://github.com/pedropro/TACO and https://arxiv.org/abs/2003.06975. Use reviewed annotations and retain each source photograph's licence. The toolkit licence is not a blanket licence for every photograph.
- **OpenStreetMap** contributors: https://www.openstreetmap.org/copyright. MapLibre's map attribution remains visible.
- **OpenFreeMap**: https://openfreemap.org/quick_start/.
- **Nominatim**: https://operations.osmfoundation.org/policies/nominatim/. User-submitted searches only, attribution, identifiable User-Agent, shared caching and at least 1.1 seconds between upstream request starts. No autocomplete or systematic geocoding.
- **MapillaryJS**: https://github.com/mapillary/mapillary-js, MIT.
- **shadcn/ui component pattern**: https://ui.shadcn.com and https://github.com/shadcn-ui/ui, MIT. Button variants and Radix-based dialog follow this pattern.
- **Ultralytics**: https://github.com/ultralytics/ultralytics and https://www.ultralytics.com/license. The proposed open college project uses the AGPL-3.0 option. Publish corresponding project source when sharing the trained application, and preserve upstream licence notices. Training code and model licensing remain relevant even though deployment uses ONNX Runtime.
- **ONNX Runtime**: https://github.com/microsoft/onnxruntime, MIT.

No Google Street View images are used. No synthetic test detections are included in the product. A model's confidence score is an internal score, not proof of a street's cleanliness.
